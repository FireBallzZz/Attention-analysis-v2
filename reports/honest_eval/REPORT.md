# Leakage-free re-evaluation of the binary attention model

Generated by `scripts/honest_evaluation.py` (raw numbers: `results.json`).
Rerun with:

```
python scripts/honest_evaluation.py
```

No existing checkpoint, dataset or report was changed.

## 1. What was wrong with the earlier evaluation

| Problem | Evidence |
|---|---|
| "Clip 007" test = training data | `analyze_clip_007.py` scores against `Anno/annotations.xml` + `Anno/ground_truth.csv`; `classroom_clip_004_v3_hardened.npz` labels match that CSV on 5,985 / 5,985 windows. |
| 2 of 3 training clips are labelled by a model | `Anno/clip_001_ground_truth.csv` and `clip_008_ground_truth.csv` agree 100% with the `*_cvat_preannotated.xml` files written by `generate_cvat_preannotations.py` (labels from `classroom_attention_head_focal_v2.pt`). The model's clip_001 labels agree with the human clip-1 annotation on only 80.8% of windows, and mark twice as many windows disengaged (15.9% vs 8.0%). |
| Split is by track ID, not by person | All clips come from `DEFENCE/classroom_01.mp4`. CVAT track IDs are per clip, so the same seat or person has different IDs in different clips and can end up in both train and "held-out". |
| Choices tuned on the reported set | Best epoch, loss config and threshold were picked on the same 6-student set that was reported. `configs/pipeline.yaml` sets `binary_threshold: 0.45`, measured on the human annotation of all clips. |

## 2. New protocol

* **Data: human labels only.**
  * clip_004: `Anno/ground_truth.csv`, 5,985 windows.
  * clip_001: `runs/Annoted file for clip 1/annotations.xml`, transferred onto the existing feature windows by per-frame box IoU ≥ 0.30, giving 4,064 windows.
  * clip_008 is dropped because it has no human labels.
  * Total: 10,049 windows, 13.6% disengaged.
* **People.** Clip-001 and clip-004 tracks are paired by seat position (Hungarian matching on mean box centre, ≤ 60 px), giving 18 pairs and **23 persons**. Only **10 persons** are ever labelled disengaged. The windows overlap by 15 of 16 frames, so there are only about **700 non-overlapping windows**.
* **Outer split.** 5-fold `StratifiedGroupKFold` grouped by person: test persons are never seen in training.
* **Inner validation.** Inside each training fold, about 25% of persons are held out. They alone choose the epoch and the threshold (whichever threshold maximises balanced accuracy).
* **Models.**
  * BiGRU: same architecture and recipe as the deployed model (DAiSEE-initialised `ManualBinaryAttentionClassifier`, frozen encoder, weighted CE, 15 epochs), 3 seeds averaged.
  * Logistic-regression baseline on window statistics.
  * Always-attentive baseline.
* **Confidence intervals.** 95% CIs come from a **person-level cluster bootstrap**: whole persons are resampled, because windows from the same person are strongly correlated.

## 3. Results

### 3.1 Leave-persons-out cross-validation (the honest number)

| Model | Accuracy | Balanced acc. | Macro-F1 | Disengaged recall | ROC-AUC |
|---|---|---|---|---|---|
| Always "attentive" | **86.4%** | 50.0% | 46.4% | 0% | 0.50 |
| BiGRU (deployed recipe) | 79.1% [69.4–87.8] | 51.9% [44.7–60.3] | 52.0% [45.0–61.7] | 14.6% [3.2–30.3] | 0.61 [0.46–0.76] |
| Logistic regression | 71.7% [59.3–82.3] | 59.0% [47.1–71.1] | 55.4% [44.5–66.3] | 41.5% [21.4–63.9] | 0.66 [0.48–0.81] |

Per seed, the BiGRU's ROC-AUC was 0.55–0.61 and its balanced accuracy 0.51–0.55. The threshold chosen on inner validation swung from 0.10 to 0.90 between folds, which shows the validation sets are too small to set it reliably.

### 3.2 Cross-segment transfer (train on one clip, test on the other)

The persons overlap here, so this is an *optimistic* bound.

| Direction | Accuracy | Balanced acc. | Macro-F1 | Disengaged recall | ROC-AUC | Always-attentive acc. |
|---|---|---|---|---|---|---|
| clip_004 → clip_001 | 81.2% | 53.0% | 51.8% | 19.4% | 0.61 | 92.0% |
| clip_001 → clip_004 | 55.1% | 63.6% | 51.2% | 76.7% | 0.60 | 82.6% |

### 3.3 Deployed checkpoint on the same human labels (contaminated, for reference)

`classroom_manual_binary_unquarantined.pt` at τ = 0.50:

| Clip | Accuracy | Balanced acc. | Macro-F1 | ROC-AUC | Always-attentive acc. | Note |
|---|---|---|---|---|---|---|
| clip_004 | 92.9% | 83.7% | 86.5% | 0.90 | 82.6% | **trained on these windows** |
| clip_001 (human labels) | 81.7% | 55.4% | 53.5% | 0.66 | 92.0% | trained on these windows but with *model* labels |

The gap between these two rows is the leakage made visible. On the clip where it learned the human labels, the model looks strong. On the clip where it learned a model's labels, it does worse than always answering "attentive".

## 4. Conclusions for the thesis

1. **No reported accuracy (95.1%, 87.7%, 80.7%, 90.2%) can be defended.** Measured without leakage, the attention classifier separates engaged from disengaged windows only slightly better than chance. Every confidence interval for ROC-AUC includes 0.5.
2. **The limit is the data, not the architecture.** The data is two 10-second clips with 23 people, of whom 10 are ever disengaged, from one camera. A simple logistic regression (no pre-training) does at least as well as the DAiSEE-initialised BiGRU. The BiGRU was not re-run without DAiSEE pre-training, so its exact contribution is not measured.
3. **Accuracy is the wrong headline metric.** With 86% attentive windows, always answering "attentive" beats every trained model on accuracy. Report balanced accuracy, macro-F1, disengaged-class recall and ROC-AUC with person-level CIs, next to the always-attentive baseline.

## 5. What would make the result defensible

1. **Label more video by hand.** Correct the clip_008 pre-annotations in CVAT and annotate at least 3–5 more minutes, ideally from a **second classroom or camera**. Have a second annotator label about 20% and report Cohen's κ.
2. **Keep one human-labelled video as a locked test set** that is never used for training, epoch choice or threshold choice.
3. **Keep the protocol in this script:** split by person, choose epoch and threshold on inner validation only, use person-bootstrap CIs, and always show the baselines.
4. **Fix the training/inference mismatch.** Extract features from detector boxes, not human boxes, and drop the 15 constant feature channels.
5. **Report the system honestly.** Present the detection, tracking, gaze and behaviour pipeline plus teacher alerts as the engineering contribution. Present attention classification as a preliminary result limited by the available labelled data.
